# George Thomas — Claude Code Marketplace

A personal marketplace registry for Claude Code plugins.

## Available plugins

| Plugin | Description |
|--------|-------------|
| [personal-retro](https://github.com/georgethomasuk/personal-retro-plugin) | Personal retrospective coach — extracts Claude Code session logs and generates AI coaching notes with themes, patterns, and probing questions. |

## Usage

Add this marketplace to your Claude Code settings (`~/.claude/settings.json`):

```json
{
  "marketplaces": [
    "github:georgethomasuk/georgethomas-marketplace"
  ]
}
```

Then install plugins from the marketplace using Claude Code's plugin management.
